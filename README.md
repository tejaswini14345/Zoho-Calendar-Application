# Calendar Workspace

A polished, dependency-free calendar workflow project with a monthly calendar, event creation, event categories, selected-day event lists, and LocalStorage persistence.

> This is an independent portfolio/learning project and is not affiliated with or endorsed by Zoho.

## Features

- Month navigation
- Jump to today
- Select any calendar day
- Add timed or all-day events
- Event categories
- Remove events
- LocalStorage persistence
- Responsive desktop/mobile layout
- No framework or build step required

## Run

Open `index.html` directly in your browser.

For local development with a simple web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
